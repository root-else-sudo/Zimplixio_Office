## 2026-05-02 - WhatsApp Notifications

- **Status:** Production ready (with sandbox constraint)
- **Issue:** WhatsApp message not delivered after pipeline runs
- **Root cause A:** `TWILIO_WHATSAPP_FROM` was originally set to the business phone number. Twilio cannot send from a non-approved WhatsApp sender.
- **Root cause B:** Twilio sandbox cannot send to the same number it sends from.
- **Fix:** Changed `TWILIO_WHATSAPP_FROM` to `whatsapp:+14155238886` (official Twilio sandbox number)
- **Constraint:** Recipient (`WHATSAPP_NOTIFY_TO`) must have sent "join [keyword]" to the sandbox number once. This is a sandbox-only requirement; a production Twilio WhatsApp sender would not need it.
